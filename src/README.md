# DevOps 17 Lab

A hands-on project to understand 17 DevOps
technologies through practical implementation.

## Application

JavaScript Hello World application using Node.js.

## Purpose

- Source control
- CI/CD automation
- Build and testing
- Code quality and security
- Infrastructure automation
- Containerization
- Application deployment

## Technologies

JavaScript, Node.js, Git, GitHub, GitHub Actions,
Jenkins, Ansible, Docker, Kubernetes and more.

## Run the application

npm install
npm start
